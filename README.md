# Zen Tags Backend (Vercel + Flask)

Environment variables (Vercel -> Project -> Settings -> Environment Variables):

| Name | Value |
|---|---|
| PLAYFAB_TITLE_ID | 423D0 |
| PLAYFAB_SECRET_KEY | your (rotated) PlayFab secret key |
| META_API_KEY | OC\|<Zen Tags Meta App ID>\|<Zen Tags Meta App Secret> |
| DISCORD_WEBHOOK_URL | your Discord webhook |
| EXTRA_ALLOWED_LIBS | optional, comma separated extra .so names |
| LIBS_REQUIRED | 0 (set 1 once the game sends NativeLibs) |
| INTEGRITY_REQUIRED | 0 |
